# Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript. It supports basic arithmetic operations such as addition, subtraction, multiplication, and division, with a user-friendly interface and real-time calculation display. Developed as part of the CodeAlpha Frontend Development Internship.
<h1>Author Name : Swayam Prakash Mishra</h1>
<br>

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Decimal calculations
- Backspace button
- AC (Clear) button
- Division by zero error handling
- Keyboard support
- Responsive design for phones, tablets, and desktops

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the calculator in your browser.
2. Click the calculator buttons to perform calculations.
3. You can also use your keyboard for numbers and operations.
